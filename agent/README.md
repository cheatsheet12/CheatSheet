# agent — Agente conversacional

Agente conversacional sobre **WhatsApp Business** para interacción con usuarios.

- **Stack:** Python
- **Entradas externas:** WhatsApp Business API, webhooks de mensajes, modelos de IA
- **Variables de entorno relevantes:** `WHATSAPP_TOKEN`, `WHATSAPP_PHONE_ID`, `WHATSAPP_WEBHOOK_VERIFY_TOKEN`, `AI_API_KEY`, `AI_MODEL`

> En `dev` y `staging` se usa un **número de prueba** de WhatsApp.
