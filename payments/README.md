# payments — Módulo de cobros

Gestión de cobros y conciliación de pagos mediante **MercadoPago**.

- **Stack:** Python
- **Entradas externas:** API de MercadoPago, webhooks de notificación de pagos
- **Variables de entorno relevantes:** `MP_ACCESS_TOKEN`, `MP_WEBHOOK_SECRET`

> En `dev` y `staging` se usa el modo **sandbox** de MercadoPago.
