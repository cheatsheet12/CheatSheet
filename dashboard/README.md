# dashboard — Panel de administración web

Frontend de administración del sistema.

- **Stack:** Next.js (React, TypeScript)
- **Consume:** API del módulo `core`
- **Variables de entorno relevantes:** definidas con prefijo `NEXT_PUBLIC_` para las
  expuestas al cliente; el resto, solo en el servidor.

> Este módulo tiene su propio `package.json` y `node_modules` (excluido por `.gitignore`).
