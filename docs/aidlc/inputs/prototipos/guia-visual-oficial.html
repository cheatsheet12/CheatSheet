Versión: Design System 2.4  ·  Fecha: Junio 2026  ·  Alcance: Web — Escritorio 1440px

Este documento define el lenguaje visual de CheatSheet: la paleta de colores, la tipografía y los componentes reutilizables que garantizan consistencia entre todas las pantallas. Cada color se referencia por su token y nunca por su valor literal.

2. Tipografía

Se emplean dos familias: DM Sans para toda la interfaz y una monoespaciada para datos e identificadores técnicos (CUIT, CAE, N.º de comprobante, montos, fechas).

2.1 Familias

FamiliaStack tipográficoUso
DM Sans"DM Sans", system-ui, sans-serifInterfaz general: títulos, cuerpo, botones y etiquetas. Auto-hospedada con next/font; el stack del sistema es sólo el respaldo.
Monoespaciada"JetBrains Mono", ui-monospace, monospaceDatos técnicos: CUIT, CAE, comprobantes, montos, tokens.

2.2 Escala tipográfica

EstiloTamañoPesoUso
Título de página30 px800 — ExtraboldEncabezado principal de cada pantalla.
Encabezado de sección20 px800 — ExtraboldDivisiones dentro de una pantalla.
Subtítulo / título de tarjeta16 px700 — BoldTítulos de tarjetas y paneles.
Cuerpo de texto14 px400 — RegularTamaño base de lectura.
Etiqueta de control / botón13 px600 — SemiboldBotones, campos y controles.
Texto secundario12 px400 — RegularDescripciones y notas.
Eyebrow / encabezado de columna10.5 px · mono600 — SemiboldEtiquetas en mayúscula y encabezados de tabla.

2.3 Pesos disponibles

  • Regular (400) — texto de cuerpo y descripciones.
  • Semibold (600) — etiquetas de controles y botones.
  • Bold (700) — títulos de tarjeta y subtítulos.
  • Extrabold (800) — títulos de página y cifras destacadas.
